Chapter 1 – Repetition: AJAX, JSON and PHP

Script: Chapter 1
Folder: /WEBAP/Exercises/ch01/ – one folder ex_xx per exercise. Comments marked TODO show where to write your code. Folders containing only a README.txt start from a copy of the previous exercise.

These exercises repeat the most important techniques of WEBAP1 and introduce json_decode(), which you need to read JSON from files and external services.

Exercise 1.1 – Associative arrays → JSON → table

Folder: ch01/ex_01/   open folder   Files provided: getStudents.php, index.html

getStudents.php contains an array of associative arrays (one per student).

  1. Complete the PHP script so that it outputs the array as JSON (header + json_encode()). Open it in the browser: what does the JSON look like?
  2. At the push of the button, load the data with $.getJSON() and display it as a table with the columns first name, last name, class and age.
  3. Add a drop-down list with the classes. The PHP script receives the selected class as URL parameter class and returns only the students of this class (array_filter() or a foreach loop).

Exercise 1.2 – Reading a JSON file with json_decode()

Folder: ch01/ex_02/   open folder   Files provided: getMovies.php, index.html, movies.json

The file movies.json contains a list of movies. The client must not load the file directly: getMovies.php reads it, filters it and returns only the matching movies.

  1. Read the file with file_get_contents() and convert it with json_decode($text, true) into a PHP array. Test with var_dump() or print_r().
  2. Return only movies released in or after the year given by the parameter from and – if the parameter genre is not empty – of this genre.
  3. Sort the result by rating, best first (usort() with <=>).
  4. The client displays the movies as list: Inception (2010) – 8.8.

Exercise 1.3 – A poll with a JSON file

Folder: ch01/ex_03/   open folder   Files provided: index.html, vote.php

Program a small poll. The votes are stored in the file votes.json on the server, e.g. {"Python": 3, "JavaScript": 5, "Java": 1, "C#": 0}.

  1. vote.php reads the file (json_decode(…, true)). If it does not exist yet, all options start with 0 votes.
  2. If an option was sent with POST ($_POST["option"]), its counter is increased and the file is saved again (file_put_contents(), JSON_PRETTY_PRINT).
  3. vote.php always returns the current results as JSON object.
  4. The client sends a vote with $.post() when a button is clicked, and displays the results as bars (width in % of all votes). The results are also shown when the page is loaded.

The web server needs write access to the folder (see chapter 10 of the script).

Exercise 1.4 – Navigating nested data in PHP

Folder: ch01/ex_04/   open folder   Files provided: school.json, school.php

The file school.json contains nested objects and arrays – exactly like the answers of real web services. Write school.php, which reads the file with json_decode(…, true) and outputs the following information as HTML (no AJAX in this exercise):

  1. The name of the school and the year it was founded.
  2. The number of sections and a comma-separated list of them (count(), implode()).
  3. The last name of the teacher of the second class.
  4. For every class: its name and the names of all students (nested foreach).
  5. For every student: the average of the grades, rounded to one decimal (array_sum(), count(), round()).
  6. What would you write in JavaScript to access the teacher’s last name of the second class? Write the answer as a comment at the end of your script.

Tip: draw the structure first. Curly braces {} become associative arrays, square brackets [] become numeric arrays.
