Chapter 8 – Project: your own single page web app

Script: Chapter 8
Folder: /WEBAP/Exercises/ch08/ – one folder ex_xx per exercise. Comments marked TODO show where to write your code. Folders containing only a README.txt start from a copy of the previous exercise.

In the project you develop your own SPA (about 18 lessons). The folder ex_01 contains the structure of a project, a planning document and a checklist. The Bookshelf (exercise 7.4) shows what a finished project can look like.

Exercise 8.1 – Project template

Folder: ch08/ex_01/   open folder   Files provided: API.md, CHECKLIST.md, PLANNING.md, index.html, api/, css/, js/

Copy the folder ex_01 to a new folder with the name of your project (e.g. ch08/bookshelf).

  1. Fill in PLANNING.md and have it accepted by your teacher before you start programming.
  2. Develop the API first and test it with the API tester, then the client.
  3. Check your project regularly against CHECKLIST.md – it corresponds to the evaluation criteria (section 8.5 of the script).
