Exercise 2.4 – URL builder

Folder: ch02/ex_04/   open folder   Files provided: index.html

Complete index.html: when the user clicks Build URL, the page builds the Open-Meteo URL from the form and displays it as a clickable link.

  1. Latitude, longitude and the number of days are always sent.
  2. The checked current values are joined with commas into the parameter current, the daily values into daily (tip: $("input[name='daily']:checked"), each(), join(",")). Leave out a parameter if nothing is checked.
  3. If daily values are requested, add timezone=auto.
  4. Build the query string with $.param(object). Click the link to check the answer.
