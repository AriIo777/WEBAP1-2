Exercise 4.1 – From parallel arrays to a list of days

Folder: ch04/ex_01/   open folder   Files provided: forecast.php, index.html

Open-Meteo returns the daily values as parallel arrays. For the client, a list of day objects is much easier to use.

  1. forecast.php loads the 7-day forecast of Luxembourg (max, min, precipitation sum, weather code) and transforms it into an array of associative arrays: [{"date":"23/11","weekday":"Monday","max":7.9,"min":2.3,"rain":0,"text":"Overcast","icon":"☁️"}, …] (for loop, strtotime(), date(), weatherInfo()).
  2. When the page is loaded, display the days in a table: weekday + date, icon + text, min, max, precipitation.
  3. The row of the warmest day gets the CSS class warm. Find it in JavaScript.
  4. Display precipitation of 0 mm as “–”.

Exercise 4.2 – Statistics with PHP array functions

Folder: ch04/ex_02/   open folder   Files provided: index.html, stats.php

stats.php receives a city, loads its 14-day forecast (geocoding + forecast) and calculates – with PHP array functions, without writing loops – the following values:

  • average of the maximum and of the minimum temperatures (array_sum(), count(), round())
  • highest maximum and lowest minimum (max(), min())
  • the date of the warmest day, formatted as Friday 27/11 (array_search())
  • total precipitation and number of rainy days with at least 1 mm (array_filter())

The client displays the values in a table. Handle unknown cities (status 404).

Exercise 4.3 – Book search with Open Library

Folder: ch04/ex_03/   open folder   Files provided: books.php, index.html

  1. books.php searches Open Library (API_BOOKS, parameters q, fields=key,title,author_name,first_publish_year,cover_i, limit=20) and transforms each result: the author list becomes one string (implode(), “unknown author” if missing), missing years become null, and cover_i becomes the URL https://covers.openlibrary.org/b/id/{cover_i}-M.jpg (or null).
  2. Sort the books in PHP according to the parameter sort: year (newest first, usort()) or title (strcasecmp()); relevance keeps the order of the API.
  3. The client displays one card per book (cover, title, author, year) and the total number of results.
  4. The checkbox only books with a cover hides/shows the cards on the client without a new request. Why is the client the better place for this filter, and PHP the better place for the transformation? (section 4.7)

Offline (mock service), the cover images cannot be loaded – display a grey placeholder (onerror or CSS).

Exercise 4.4 – Sorting and filtering on the client

Folder: ch04/ex_04/   open folder   Files provided: index.html, rates.php

  1. rates.php combines two answers of the Frankfurter API: the rates of the selected base currency and the names of the currencies. It returns a list of objects {"code":"USD","name":"United States Dollar","rate":1.0864}.
  2. The client loads the list once when the page is loaded or the base currency changes, stores it in a variable and displays it.
  3. While the user types into the filter field (event input), only currencies whose code or name contains the text are displayed – without a new request.
  4. Clicking on a column header sorts the table by this column; a second click reverses the order (Array.sort() with a compare function, localeCompare() for texts).

Exercise 4.5 – A bar chart with CSS

Folder: ch04/ex_05/   open folder   Files provided: index.html, temperatures.php

Visualise the 14-day forecast of a city as a bar chart – without a chart library, only with div elements whose height is calculated in JavaScript.

  1. temperatures.php returns {"city":"Luxembourg","days":[{"label":"Mon 23","max":7.9,"min":2.3}, …]}.
  2. For every day, add a column with a red bar (max) and a blue bar (min) and the label below. The height of a bar is proportional to the temperature: the highest value of all days = 150 px (Math.max(...array)).
  3. Show the value in a tooltip (attribute title).
  4. For advanced users: negative temperatures – find a solution so that the bars still make sense (e.g. calculate the height from the lowest value).
